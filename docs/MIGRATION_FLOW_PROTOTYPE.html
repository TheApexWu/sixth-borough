Robert Moses pushed the Cross-Bronx Expressway through East Tremont and Tremont between 1948 and 1972, displacing roughly 60,000 residents — many of them working-class Jewish, Black, and Puerto Rican families. Co-op City (1968–1973) absorbed a significant share. Others moved to outer Bronx neighborhoods, then Westchester, then over decades to South Florida and the Carolinas. The highway split the neighborhood physically and the community demographically.

Robert Caro, The Power Broker: Robert Moses and the Fall of New York, Knopf, 1974, ch. 37–39. Displacement count is Caro's own estimate, widely cited.

Encoding range — four variants

Same primitive, different parameter values. The four variables Marvens needs to control per event: height (intensity), top-width (spread), tilt (direction), era band color.

Year-slider activation (mockup)

Cones are dim/inert until the slider window enters their event range. When active, particles drift slowly upward. When inactive, only the faint cone outline remains as a "ghost of an event."

Locked grammar

  • Cool PS2 palette only. Deep navy → washed periwinkle → memory blue. Single dusty-gold accent for the origin click-target.
  • Slow upward drift. Dense at base, sparse at top. Vertical bias in all motion.
  • Soft dispersal at top. Particles spread outward, never plume.
  • Origin centroid, not specific building. Anchor reads as a neighborhood marker.
  • Click-panel pairing. Every cone is clickable → opens metadata with documented count + source citation.
  • Year-slider activation. Inactive = faint outline ghost; active = particles flowing.
  • Tilt encodes direction. Cone leans toward vector mean of destination tracts when known.

Anti-patterns — do not ship

  • Red / orange / yellow particles. Reads as fire. Kitsch. Anti-community.
  • Fast turbulent motion. Reads as smoke or destruction.
  • Solid plume shape. Reads as a chimney smokestack.
  • Photorealistic shading or PBR. Kills the PS2 memory grammar.
  • Cone without a click-panel. Reads as decorative noise.
  • Cone shaded with a literal flame gradient. The neighborhood is not on fire.
  • Rapid pulse / strobe. The data is solemn, not a rave.

Authoring contract (Marvens → Carson)

Per-event Blender deliverable

  • Mesh: inverted cone with particle-emitting volume inside. Vertex count <2,000.
  • Lighting: vertex normals only, no UVs needed (vertex-lit).
  • Animation: embedded vertex animation texture (OpenVAT) for slow upward drift, ~4 second loop.
  • Tilt: baked into geometry if directional, or as a runtime parameter Carson sets per event.
  • Color: vertex color attribute encoding the era band. Carson reads + applies via shader.
  • Export: assets/migration-flows/{event_id}.glb
  • Manifest: sibling to ghost manifest at assets/migration-flows/MANIFEST.json
