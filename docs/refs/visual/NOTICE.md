# Notice — Visual Reference Assets

The image files in this directory are screenshots from **Shin Megami Tensei III: Nocturne** (Atlus, 2003) and the HD Remaster (Atlus, 2020/2021), used as a fair-use mood board for internal design alignment between teammates on the Sixth Borough hackathon project.

- All rights to Shin Megami Tensei III: Nocturne and its imagery belong to Atlus / Sega.
- These references are not redistributed, monetized, or used in any shipped product.
- Sixth Borough does not contain any Atlus intellectual property in its source code, models, textures, or shipped assets.
- The references exist solely so the team can converge on a shared visual language ("PS2 Vortex World aesthetic") without requiring everyone to play through the game.

If this folder ever needs to be removed for any reason (publication, distribution, licensing concerns), the doc at `docs/VISUAL_DIRECTION.md` is written to remain useful via text descriptions alone.
